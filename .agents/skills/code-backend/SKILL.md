# Goal
Implement GrupoXpert's Application and Infrastructure logic following the DDD pattern and clean architecture, using 100% SPANISH for domain nomenclature and English for structural components.

# Layer Structure
Implement code in the following locations:

## 1. GrupoXpert.Application/
- `Common/`: `Interfaces/` (`IUnitOfWork.cs`), `Behaviors/`.
- `[Functionality]/`: (e.g., Perfil).
  - `Commands/`: `ActualizarPerfilCommand.cs`, `ActualizarPerfilHandler.cs`.
  - `Queries/`: `ObtenerPerfilQuery.cs`, `ObtenerPerfilHandler.cs`.
  - `Dtos/`: `PerfilDto.cs`.

## 2. GrupoXpert.Infrastructure/
- `Persistence/`:
  - `AppDbContext.cs`: Data context.
  - `Configurations/`: EF Core configurations (`PerfilConfiguracion.cs`).
  - `Repositories/`: Implementation of domain repositories.
  - `appsettings.json`: (Exclusive for DBA, contains `sa` credentials for migrations and DDL).
- `Services/`: External integrations (Stripe, Turnitin).
- `DependencyInjection.cs`: Service registration (reads connection string from WebApi).

## 3. GrupoXpert.WebApi/
- `Controllers/`: API endpoints.
- `appsettings.json`: Main app configuration. Contains the `CadenaConexion` key (app credentials, without DDL permissions).

# Instructions
- Use **MediatR** to orchestrate use cases.

- Method and variable names must always be in Spanish for domain logic.

- ✅ **Dependency Rule**: Application only depends on Domain. Infrastructure depends on Application and Domain.
